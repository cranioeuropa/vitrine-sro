# Vitrine SRO

Repositório-laboratório para validar padrões de engenharia, governança de commits e automações da NAVE antes de aplicá-los aos projetos em produção.

## Objetivo inicial

- adotar Conventional Commits;
- padronizar mensagens geradas pelo GitHub Copilot;
- registrar escopos claros por módulo ou capacidade;
- preparar o repositório para futuras automações de changelog, revisão e CI.

## Formato de commit

```text
tipo(escopo): descrição
```

Exemplo:

```text
feat(governance): add conventional commit instructions
```
## Primeiro teste da memória de construção

Este repositório iniciou sua operação utilizando GitHub, VS Code e GitHub Copilot para registrar a evolução da NAVE.
